## Cheapest exact Hodge-side falsifier

Consider vector spaces over `Q`

`C = C0 ⊕ C1`, `H = H0 ⊕ H1`

and a block map

`cl = cl0 ⊕ cl1 : C -> H`.

Take

- `C0 = H0 = Q`,
- `cl0 = id`,
- `C1 = 0`,
- `H1 = Q`,
- `cl1 : 0 -> Q`.

The decomposition is exact and the first component is completely source-realized. Nevertheless `cl` is
not surjective because the nonzero target component `H1` has no source preimage.

Therefore the weak inference

> exact decomposition + successful discharge of some pieces  
> `=>` total source surjectivity

is false.

The repaired inference is equally exact: for a block-diagonal source-to-target map, every root-relevant
target block must either be hit by a proved source map or be proved zero (or be discharged by another
independently justified assembly mechanism). An unresolved nonzero target block remains a proof
obligation.

This elementary countermodel carries no novelty claim. Its purpose is to make the research discriminator
machine-checkable.
