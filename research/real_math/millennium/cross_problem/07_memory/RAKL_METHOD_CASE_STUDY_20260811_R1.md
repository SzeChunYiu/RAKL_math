## Recurring pathology 1 — surrogate/root-coordinate faithfulness

Across at least P-vs-NP, RH, BSD, Hodge, Yang–Mills and Navier–Stokes, a repeated shape appears:

```text
locally meaningful / mathematically valid object
        !=
root-critical quantity
```

unless a separate interface proves preservation.

Observed manifestations:

- P-vs-NP: maximal raw closure mass can coexist with zero exact cover cost.
- RH: manifestly positive norm does not imply Li positivity before an RH-coupled faithfulness edge is discharged.
- BSD: augmentation/discrete order can contain correction and extra-zero structure not equal to complex Taylor order.
- Hodge: Hodge persistence/detector information does not itself construct a Chow source or kill a detector-kernel obstruction.
- Yang–Mills: a correct abstract spectral lemma does not produce OS source density, RG transport or a continuum physical gap.
- Navier–Stokes: centered local decay or a local rigidity interface does not rule out moving-center/far-field escape without a global inheritance theorem.

### Competing diagnoses

`D1`: this is simply the unavoidable mathematical structure of hard open problems; no framework change can help.  
`D2`: RAKL atomizes local obligations well but does not make the **surrogate-to-root preservation edge** explicit early enough, so agents spend cycles improving a local coordinate before proving it is charged by the root.  
`D3`: the current cross-problem audit already solves the process problem; observed recurrence is historical lag, not a framework gap.

**Current status:** `SUPPORTED_PROCESS_PATTERN`, not a causal framework diagnosis. D2 is strong enough to benchmark but not to promote automatically.

## Framework improvement hypothesis A — RootCoordinatePreservationReceipt

Proposal-only object; name not prescriptive.

Before an agent treats a surrogate, local invariant, representation, detector, asymptotic rate, discrete order, local lemma or numerical quantity as progress toward a root obligation, freeze:

```text
root_claim_id / root_coordinate
surrogate_or_local_coordinate
exact bridge/interface map
enabling assumptions
non-compensatory obligations
known disanalogies
source/target authority
cheapest hostile world where surrogate is favorable but root is not
unproved interface edges
reverification triggers
```

This should be a **search-control gate**, not a theorem gate. It should be mandatory before expensive candidate generation or progress/promotion claims, but not before free-form brainstorming.

### Expected benefit

- kill false-progress representations earlier;
- reduce candidate churn and repeated surrogate optimization;
- turn “local success, root still open” into an explicit gluing/interface residual;
- improve cross-domain retrieval because deep cues can index the bridge type rather than surface vocabulary.

### Possible regression

- added overhead can suppress useful exploratory heuristics;
- a too-rigid root-coordinate schema may force premature formalization of genuinely emergent representations;
- hostile worlds may be unavailable early in a frontier problem.

### Cheapest discriminating benchmark

Replay the six historical episodes above with and without the receipt. Measure:

```text
candidate generations before bridge defect detected
repeat-failure rate
source/tool calls until route pruning
false progress assertions
residual contraction
```

The receipt should flag the known defects without rejecting the surviving scoped use of each representation. A hostile near-miss set must include cases where the surrogate is genuinely faithful so the gate does not become a universal blocker.

## Positive motifs observed

1. **Dependency-first source audits** repeatedly outperform theorem invention when a route may be root-equivalent under a new name (RH, BSD, Hodge).
2. **Cheap hostile controls before candidate generation** remove whole representation families at low cost (PNP all-rectangle world, NS concentration, YM hidden-source world, XM005 moving-core world).
3. **DifferenceWitness-scoped transfer** is useful when only the audit operation transfers, not literal mathematics.
4. **Chronology preservation** is improving: RH-ANA-002 uses an actual v3 `TaskEpisode` and leaves competing diagnoses unpromoted; XM004 preserves retrospective timing rather than manufacturing pre-candidate credit.
5. **Representation rotation after a scoped failure** is healthier than parameter search inside a dead family (RH norm -> arithmetic cancellation; BSD scalar order -> graded/derived object; PNP raw closure mass -> pair-charged ancestry).
6. **Local lemma + explicit gluing residual** is preferable to an inflated theorem claim (Yang–Mills dense-source spectral lemma).
