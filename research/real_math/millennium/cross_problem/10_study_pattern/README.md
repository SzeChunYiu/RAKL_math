# Proposal-only experience shadow pilot

This directory is an application-local, pre-registered **shadow study**. It
does not adopt or validate framework PR 118. The accepted framework authority
remains `15f1c3affe5bf85ba41ff0ab65b25ba19e0d28a3`.

The delta tests one narrow question: after the exact canonical success-tool and
failure-lattice queries have been frozen, can content-bound, quarantined
experience proposals improve the priority of the next research action at
matched resources?

The enforced order is:

1. query the canonical research-tool inventory;
2. query the canonical failure lattice;
3. freeze the canonical `ResearchMemoryReview`;
4. load quarantined episode and lesson proposals;
5. apply at most a `0.1` search-priority advisory without changing eligibility;
6. record `NEXT_STEP_PROPOSED`.

The two episode examples deliberately preserve both sides of the lineage. The
support record describes the exact-pin runner's source-scoped success. The
contradiction record preserves the later import verdict that downgraded the
requested authority and performed no inventory, lattice, or framework
mutation. The lesson is therefore not a `ResearchTool`; it is a falsifiable
`PROPOSAL_ONLY` routing advisory.

The matched A/B pilot is frozen before any pilot result. It contains two
known-answer and two near-solved calibration cases, paired resources, evaluator
separation, and the required repeat-failure, valid-next-action, cost, and
false-lesson metrics. A positive development result would still require fresh
assurance on unseen cases. A null or falsification narrows or retires the
proposal.

## Authority boundary

Nothing here can create tool, proof, gluing, theorem, Millennium-root,
framework, or independent-review authority. The JSON schemas use constants and
closed objects so caller-supplied authority fields fail validation. The focused
test also plants hostile authority and chronology mutations.

Every example and preregistration is content-self-hashed as canonical JSON with
its `artifact_hash` set to the empty string during hashing. Git commit/tree/blob
bindings for these non-circular source artifacts are recorded in a successor
binding receipt after the source commit exists.
