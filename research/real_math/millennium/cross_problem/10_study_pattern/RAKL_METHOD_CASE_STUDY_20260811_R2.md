## Cross-problem action: XM006 quantifier-order calibration

XM006 was selected because it sharpens the broad root-faithfulness pattern into a narrower falsifiable subfamily.

### Source atom

`NS-B1a1`: scale-neutral local energy ledger versus global descendant assembly/termination.

### Target atom

`YM-S1b1 / YM-S1a2`: fixed-source covariance/spectral asymptotics versus a changing source/support/RG family.

### Common abstraction

For an auxiliary object `x`,

```text
for every fixed x:
    limsup_n a_n(x)^(1/n) <= q < 1
```

does not imply

```text
limsup_n sup_x a_n(x)^(1/n) <= q
```

or the corresponding diagonal statement for a root-facing sequence `x_n`.

### Enabling assumptions

- source and target each expose an auxiliary object/family index;
- the root-facing construction changes or ranges over that object;
- the handoff can be represented as quantifier order or a growth modulus.

### Disanalogies

- Navier–Stokes is multiscale additive assembly;
- Yang–Mills is source/support-family asymptotic spectral transport;
- no PDE estimate, gauge-theory estimate or theorem transfers between them.

### Cheapest exact falsifier

For `0<q<1`, set

```text
m(n,k) = q^max(n-k,0).
```

For every fixed `k`, `m(n,k)^(1/n) -> q`, while along `k=n`, `m(n,n)^(1/n)=1`. Equivalently, if `m_n <= C_{k(n)}q^n`, the target-side object to control is `C_{k(n)}^(1/n)`. Subexponential prefactor growth preserves the rate; exponential growth can change it.
