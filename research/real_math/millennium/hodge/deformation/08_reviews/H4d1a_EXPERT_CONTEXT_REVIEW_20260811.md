## Atom under review

`H4d1a`: for a smooth projective family, a fixed Hodge-locus branch `T`, and an already algebraic chosen central witness, determine whether the obstructions generated specifically by lifting that witness along `T` lie in an independently constructed envelope `B_{T,m}` on which the Hodge/semiregularity detector is faithful. This is a witness-propagation atom. It does not address root initial algebraicity of an arbitrary rational Hodge class.

## 1. VHS / Hodge-locus lead

**Background:** variations of Hodge structure, infinitesimal period maps, Hodge loci, monodromy and variational Hodge questions.

**Evidence inspected:** Cattani–Deligne–Kaplan context inherited from H4d1; Kloosterman arXiv:2104.14845; Liu–Shen arXiv:2602.13951; H4d1a context packet.

**Finding:** equations defining the Hodge-preserving base directions can make `T` computable, but `T` lives on the base. It does not identify the image of the chosen cycle-witness deformation functor. A candidate envelope constructed from Hodge equations alone would repeat the parent category error.

**Strongest objection:** `T_{s0}T` can be strictly larger than the projection of geometric witness directions. Base compatibility cannot define `B_{T,m}` without a separate witness map.

**Cheapest falsifier:** in a special family with explicit Hodge and flag-Hilbert loci, compute both tangent images and check whether they agree. Any mismatch blocks the naive base-only envelope.

**Vote:** `ACCEPT_CALIBRATION / BLOCK_THEOREM_INVENTION`.

## 2. Algebraic-cycle / witness-moduli lead

**Background:** Hilbert and Chow spaces, lci cycles, rational cycle coefficients, deformation of embedded/subscheme witnesses.

**Evidence inspected:** H4d1 witness-projection calibration; Kloosterman; Nishinou; rational signed-cycle bookkeeping from the parent lane.

**Finding:** `B_{T,1}` should be defined from a pre-existing deformation/obstruction morphism for the chosen witness category, restricted by the branch directions. Defining it as “the obstructions that occur for successful branch lifts” is circular. For a rational cycle represented by signed components, the componentwise deformation interface and class equation must remain explicit.

**Strongest objection:** one Hilbert point does not generally represent a rational signed cycle, and changing witness category can change the obstruction group. A putative universal envelope may be ill-typed.

**Cheapest falsifier:** choose one source-controlled witness category and require a completely explicit tangent/obstruction map before any comparison with the Hodge detector.

**Vote:** `ACCEPT_SCOPED_WITNESS_MAP / REJECT_UNIVERSAL_ENVELOPE_LANGUAGE`.

## 3. Semiregularity / derived-obstruction lead

**Background:** cotangent-complex deformation theory, semiregularity maps, reduced obstruction theories, perfect-complex moduli.

**Evidence inspected:** Buchweitz–Flenner arXiv:math/9912245; Pridham arXiv:1112.6001; Nishinou arXiv:2009.01651; `F-H4D1-DETECTOR-KERNEL-GAP`.

**Finding:** reduced obstruction theory supplies a genuine mechanism for discarding ambient obstruction directions, but “reduced” is not synonymous with “reachable from T”. H4d1a must prove the factorization from branch directions into the proposed reduced object and then prove detector faithfulness there. First-order success does not establish the same object at higher Artin order.

**Strongest objection:** the desired result can be made tautological by quotienting away exactly the kernel encountered after the fact. The reduced object must be defined functorially before observing the desired vanishing.

**Cheapest falsifier:** check whether the proposed `B_{T,1}` intersects the known detector kernel. If it does, the parent failure survives unchanged. If it does not, open a separate second-order test rather than claiming all-order lifting.

**Vote:** `ACCEPT_DIFFERENCE_WITNESS / BLOCK_ALL_ORDER_PROMOTION`.
