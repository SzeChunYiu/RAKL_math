# H4d1a first-order branch-detector compatibility no-go

**Date:** 2026-08-11  
**Atom:** `H4d1a`  
**Authority:** `SOURCE_BOUND_ROUTE_PRUNING / FORMAL_FIRST_ORDER_NO_GO / NO_HODGE_THEOREM / ROOT_AUTHORITY_NONE`

## Registered question

The frozen H4d1a packet proposed a branch-reachable first-order obstruction envelope
`B_{T,1} subseteq Ob_1` for a fixed algebraic witness and a fixed Hodge-locus
branch `T`.  The hoped-for strict weakening was:

1. every obstruction generated by lifting the witness along `T` lies in `B_{T,1}`;
2. the same Hodge/semiregularity detector `sigma : Ob_1 -> H_1` is injective on
   `B_{T,1}`;
3. `B_{T,1}` is independently defined before desired vanishing is known; and
4. a useful calibration should ideally have `0 < B_{T,1} < Ob_1`.

The parent H4d1 calibration, however, already records the compatibility relation
that motivates the detector route: for a Hodge-preserving first-order direction,
the detector image of the corresponding geometric obstruction vanishes.  The
cheapest H4d1a falsifier is therefore to combine these two registered statements
before searching for a special family.

## Typed first-order interface

Fix one source-controlled witness deformation problem.  Let

`delta_1 : T_{s0}S -> Ob_1`

denote the first-order branch-relative geometric obstruction map, and let

`sigma : Ob_1 -> H_1`

be the same Hodge/semiregularity detector used by the parent route.

Let `T` be a Hodge-locus branch through `s0`.  The parent compatibility statement
has the form

`sigma(delta_1(v)) = 0  for every v in T_{s0}T`.

Define the H4d1a reachable obstruction envelope exactly as the frozen packet
requires:

`B_{T,1} := delta_1(T_{s0}T)`.

No successful lift is used in this definition.

## Scoped no-go

From the two displayed equations,

`B_{T,1} subseteq ker(sigma)`.

Consequently,

`sigma|_{B_{T,1}} injective  =>  B_{T,1} = 0`.

Equivalently, if `B_{T,1}` is nonzero, the restriction of the same detector to
`B_{T,1}` cannot be injective.

This is elementary linear algebra.  Its research value is not mathematical
depth but route correction: the predeclared
`PROPER_NONZERO_AND_KERNEL_FREE` branch is incompatible with the same-detector
first-order representation whenever Hodge persistence is exactly what forces
`sigma(delta_1(v))=0`.

## Expert-cell cross-check

These are same-context analytical roles, not independent reviewers.

- **VHS/Hodge-locus lead.** The branch condition is base-side Hodge persistence.
  If the parent detector translates failure of Hodge persistence, its value
  vanishes on the tangent of `T`. **Vote:** accept the compatibility premise at
  the source scope; do not generalize beyond the detector actually identified.
- **Cycle/witness-moduli lead.** `B_{T,1}` must be the image of a pre-existing
  witness obstruction map, not a post-hoc set of successful lifts. Under that
  definition the containment is immediate. **Vote:** accept.
- **Semiregularity/derived-obstruction lead.** A reduced obstruction theory may
  change the obstruction object, but merely restricting the same `sigma` to its
  own kernel cannot restore faithfulness on a nonzero image. **Vote:** prune the
  nonzero same-detector branch; alternate obstruction objects require a fresh
  child.
- **Special-family calibration lead.** The earlier source addendum suggested
  reading a rigid chosen-witness control as a `ZERO` obstruction envelope. That
  inference is not automatic: rigidity concerns the image of witness
  deformations in base directions, whereas `B_{T,1}` is an image in an
  obstruction object. The source can remain a hostile tangent-mismatch control,
  but its exact `FULL/ZERO/PROPER_NONZERO` obstruction classification needs the
  actual source obstruction sequence. **Vote:** correct the representation,
  preserve the old text as negative history.
- **Adversarial falsification lead.** Quotienting away `ker(sigma)` after
  observing the failure would make the detector injective by construction while
  discarding precisely the obstruction that must be proved zero. That is
  tautological. **Vote:** reject.
- **Formal/novelty/learning-control lead.** The statement is a scoped
  first-order method impossibility, not a theorem toward the Hodge conjecture.
  It creates no root or novelty authority. **Vote:** register route-pruning and
  open a smaller child.

## Residual opened: H4d1b

The smallest non-circular same-detector successor is not to search for a
nonzero kernel-free envelope.  It is to prove directly, from source-specific
witness geometry, that

`delta_1|_{T_{s0}T} = 0`,

equivalently `B_{T,1}=0`, without assuming the desired lift or full
semiregularity.  In incidence-language this asks whether the Hodge-branch tangent
is independently contained in the image of the chosen witness deformation map.

Any first-order success must then open a separately frozen higher-Artin-order
child.  Formal lifting, algebraization, monodromy/global continuation and the
root initial-existence problem remain separate obligations.

A genuinely different detector or obstruction object is also logically
possible, but it must be introduced as a fresh representation with its own
source-bound compatibility and falsifier rather than as a silent repair of
H4d1a.
