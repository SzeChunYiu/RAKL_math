# HM1b same-context expert cell — algebraic generator coverage

**Authority:** `SAME_CONTEXT_REVIEW_ONLY / NOT_INDEPENDENT_REVIEW / NO_MATHEMATICAL_CANDIDATE`

**Active atom:** `HM1b` — determine whether a target rational Hodge class can be covered by a theorem-backed closure of actual algebraic correspondences/source classes, with every residual Hodge component explicitly discharged.

## 1. Hodge structures / cycle-map lead

**Background:** pure rational Hodge structures, Tate twists, Chow groups, cycle maps, Lefschetz and support filtrations.

**Finding:** expressing `alpha` as a Hodge morphism `Q(-p) -> H^{2p}(X,Q)` makes the coverage obligation explicit. A generator route is useful only if the generators have Chow sources and the target morphism is proved to lie in their closure.

**Strongest objection:** a “spanning” statement can hide the Hodge conjecture itself if the generator family is defined by the unknown preimages.

**Delegated test:** expand the generator family independently of `alpha`; require an exact target-coverage theorem and mark every residual rational Hodge substructure.

## 2. K3 / hyperkähler correspondence lead

**Background:** K3 Hodge lattices, Torelli/moduli theory, hyperkähler `H^2`, algebraic correspondences.

**Finding:** Buskin and Markman are positive controls: restrictive Hodge-isometry classes can be algebraized by geometric/coherent-sheaf correspondence mechanisms, and algebraic correspondences compose.

**Strongest objection:** isometry algebraization is a highly structured `H^2` problem. It cannot be promoted to arbitrary Hodge morphisms or higher codimension.

**Delegated test:** record the exact morphism class generated in each theorem and fail any transfer that drops the isometry/lattice/moduli hypotheses without a replacement theorem.

## 3. Motives / Tannakian category lead

**Background:** Chow motives, motivated motives, absolute Hodge classes, tensor categories and realization functors.

**Finding:** André/Deligne provide powerful target/enlarged-category structure but clarify the category boundary: motivated or absolute-Hodge authority is not Chow authority.

**Strongest objection:** an elegant motivic generator system may solve fullness only in a larger category and silently assume algebraicity of projectors/inverse Lefschetz operations.

**Delegated test:** list every projector, inverse, correspondence and tensor operation; attach `CHOW_ALGEBRAIC`, `MOTIVATED_ONLY`, or `TARGET_ONLY`. Any non-Chow generator blocks root use.

## 4. Derived / moduli / kernel lead

**Background:** Fourier–Mukai transforms, universal sheaves, Chern characters, moduli spaces and algebraic kernels.

**Finding:** Buskin/Markman and the earlier Arapura examples show why actual kernels are valuable: their Chern classes provide source-bearing correspondence data. Patel–Zhang likewise constructs cycles geometrically rather than inferring them from target labels.

**Strongest objection:** existence of a universal object is special geometry. A kernel can generate a subspace without covering the requested `alpha`.

**Delegated test:** require `(kernel class, source variety, induced cohomology map, source algebraicity, image/coverage statement)` as separate fields.

## 5. Adversarial source-transfer / falsification lead

**Background:** counterexamples, hidden standard-conjecture assumptions, category mismatch and logical sufficiency audits.

**Finding:** the primary HM1a failure remains active. Correspondence to a simpler-looking source does not help if the source Hodge class is itself open. Kamenova–Kumar is therefore a useful hostile calibration for source-problem relocation.

**Strongest objection:** “related by an algebraic correspondence” is not equivalent to “all target Hodge classes have algebraic source preimages.”

**Delegated test:** trace an arbitrary target class through the correspondence and ask exactly which source class must be algebraic. If that statement is open/root-like, label `SOURCE_PROBLEM_RELOCATED`.

**Delegated test:** use positive and hostile controls, including wrong-category, source-relocation, root-like coverage and unproved-complement cases. Preserve exact current RAKL gate chronology.
