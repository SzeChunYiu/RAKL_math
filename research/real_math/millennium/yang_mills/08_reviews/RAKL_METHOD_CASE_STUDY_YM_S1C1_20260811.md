## Framework-improvement hypotheses

### H1 — `FRESH_SOURCE_COLLISION_GATE`

**Target:** problem-fibre compilation/search policy.

When a newly available primary source explicitly claims an active residual, rank a source-collision audit ahead of theorem invention. Bind source theorem IDs, source-to-root coordinate map, revision date, and cheapest internal falsifier.

**Expected benefit:** fewer duplicate theorem attempts and faster detection of hidden bridge assumptions.

**Regression risk:** noisy or sensational preprints could consume search budget.

**Cheapest benchmark:** this YM episode plus one fresh source that survives the audit and one irrelevant fresh source that should be rejected by scope/DifferenceWitness before deep work.

### H2 — `V3_ADOPTION_HANDSHAKE`

**Target:** cross-repository runtime/bootstrap.

At the start of an application run, return one machine-readable capability/authority manifest containing the current framework SHA, application-side v3 schema versions, accepted shadow artifact types, memory-precedence authority, and promotion-disabled fields. Refuse locally invented telemetry shapes when a canonical application schema exists.

**Expected benefit:** prevents partial adoption where an agent reads new framework concepts but writes incompatible application artifacts.

**Regression risk:** a too-rigid handshake could block useful exploratory telemetry during schema migration.

**Cheapest benchmark:** replay this mid-run schema change and require the agent to detect the canonical proposal schema before writing its first durable episode; include a compatibility case where no application-side schema exists and a local proposal-only fallback is allowed.
