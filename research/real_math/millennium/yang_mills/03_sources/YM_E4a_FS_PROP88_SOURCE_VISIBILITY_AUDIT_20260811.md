## Source-observed mismatch

Proposition 8.8 states that if the OS two-point function of a **fixed nonzero gauge-invariant local observable** decays uniformly as `exp(-m_* t)`, then the full Hamiltonian gap on `Omega^perp` is at least `m_*`.

The proof correctly establishes, for the chosen centered observable `A`,

`C_A(t)=<Omega, A exp(-tH) A Omega> = integral exp(-lambda t) d mu_A(lambda)`

and from the exponential bound obtains

`supp(mu_A) subset [m_*, infinity)`.

That conclusion controls the spectral measure of `A Omega`, equivalently the cyclic subspace generated by `A Omega`. The next sentence upgrades it to

`sigma(H|Omega^perp) subset [m_*, infinity)`

without a hypothesis that this single source generates/detects the whole vacuum-orthogonal physical space. That upgrade is not licensed by the preceding argument.

## Exact falsifier

Let the physical Hilbert space have orthonormal basis `{Omega, e_low, e_high}` and let

`H Omega = 0`, `H e_low = epsilon e_low`, `H e_high = M e_high`

with `0 < epsilon < m_* <= M`.

Take a centered self-adjoint observable with `A Omega = e_high`, for example

`A = |e_high><Omega| + |Omega><e_high|`.

Then

`<Omega, A exp(-tH) A Omega> = exp(-M t) <= exp(-m_* t)`

for all `t>=0`, yet the full Hamiltonian gap is `epsilon < m_*`. The hidden vector `e_low` is orthogonal to the source cyclic subspace and is invisible to this correlator.

This is not a new obstruction. It is an exact instantiation of the already stored Yang–Mills failure `F-YM-S1A-RESTRICTED-SOURCE-HIDDEN-STATE` and the `G4` source-family spectral-visibility obligation.

## Correct interface

A sourcewise clustering argument can support a **full** gap only after an explicit completeness interface is supplied. Sufficient forms include:

1. a family `S={A_i Omega}` with dense linear span in `Omega^perp` and one common asymptotic rate `m_*>0` for every source in the family; or
2. a direct operator-norm estimate `||exp(-tH) P_perp|| <= C exp(-m_* t)` on the full vacuum-orthogonal physical space.

The first form is exactly the interface previously isolated in `YM-S1a1-C001`: source density/cyclicity plus one common rate converts source spectral support to global spectral exclusion.

The source itself contains a materially stronger formulation in Theorem E.4: the same exponential estimate is required for **every** centered gauge-invariant local observable, and the proof explicitly invokes density of those vectors. Thus the audit exposes an internal statement/interface inconsistency, not evidence that no repair exists.
