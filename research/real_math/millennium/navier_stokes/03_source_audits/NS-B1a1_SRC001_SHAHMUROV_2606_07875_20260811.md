## 2. Frozen source statements

The following v1 statements are jointly load-bearing for this audit.

### S1 — singularity gives arbitrarily small forcing packets

Appendix A states that if a singularity occurs at terminal time `T`, there are arbitrarily small packets whose score reaches the local regularity threshold. Lemma A.1 then asserts a sequence `R_k -> 0` of singularity-forcing packets.

### S2 — minimal dyadic singularity-forcing packet

In the proof of Lemma A.1, after asserting arbitrarily small threshold packets, the text instructs the reader to choose, among all such packets, one with **minimal dyadic scale**, followed by earliest terminal time and a normalized lattice center.

### S3 — scale is the primary well-founded terminal coordinate

Definition 9.1 declares the strict terminal coordinates to be lexicographically ordered with `scale` first, followed by terminal time, spatial lattice position and active-hull rank. The scale coordinate is dyadic. A terminal sequence is then selected so that no strict descendant remains after passing to a subsequence.

### S4 — smaller physical scale is a terminating improvement

Lemma 12.3 says each selected descendant either has strictly smaller physical scale, lower selected-output rank, or spends a definite positive finite currency. Its proof separates these cases: a descendant either decreases scale or rank; **if neither decreases**, an event is charged to one of the finite currencies.

### S5 — terminality discharges selected-output routes

The selected-output routing and rank-zero conventions repeatedly treat a strict descendant as an exit from the current branch. The final reduction proof invokes a terminal sequence in which outputs and descendants have been selected or exhausted.

## 3. Atomic logical falsifier

Let the dyadic singularity-forcing scales be

```text
S = {2^{-n} : n >= N}.
```

This is the simplest abstract model of the source's own premise that forcing packets exist at arbitrarily small dyadic scales.

Then:

1. `S` has no minimal positive element: for every `2^{-n}` in `S`, the smaller `2^{-(n+1)}` is also in `S`.
2. If a strict descendant may be selected merely because it has smaller physical scale, there is an infinite chain

```text
2^{-N} > 2^{-(N+1)} > 2^{-(N+2)} > ... .
```

3. Therefore the physical-scale coordinate, oriented so that smaller scale is an improvement/descendant, is not well founded.
4. Secondary lexicographic coordinates cannot repair the absence of a minimum in the primary coordinate.

This is an order-theoretic counterexample to the **selection/termination rule as written**, not a Navier–Stokes counterexample.

## 4. Search for an internal repair

The full v1 text was searched for a repair that would make the scale descent finite or otherwise prove a terminal selector. No explicit repair was found. In particular:

### R1 — finite-scale truncation

No finite lower cutoff `R >= R_min` is registered in the terminal selector. Such a cutoff would create a minimum at each finite stage, but a proof would still need to show that terminal objects selected at the cutoffs admit a limit with the required no-descendant property as `R_min -> 0`. That is not the same as choosing a global minimal forcing scale.

### R2 — reversed scale order

Reversing the scale order could make a largest forcing scale eligible for selection in a bounded window, but it would no longer justify the paper's repeated use of a **smaller** physical scale as a strict improvement/descendant. It would require a rewritten stopping argument.

### R3 — finite selected-output rank

The rank set `4 > 3 > 2 > 1 > 0` is finite, so it can stop repeated **rank decreases**. But rank zero itself includes strict-descendant selection. A sequence can repeatedly exit the finite rank system to a smaller-scale descendant and restart. Finite selected-output rank alone therefore does not bound the number of scale descents.

### R4 — finite currencies

Lemma 12.3 charges a positive currency only when neither scale nor rank decreases. On the paper's own case split, scale decrease need not spend a registered positive currency. Bounded currency therefore does not by itself exclude an infinite chain of uncharged strict scale descendants.

### R5 — compactness / selected-output profile extraction

Compactness after rescaling may produce an ancient profile along a sequence `R_k -> 0`. That can be a valid blow-up-analysis operation, but it does not prove that some member of the original forcing-packet family has minimal physical scale or that the limiting profile has no finer forcing descendant. A separate persistence/no-descendant theorem is required.

### R6 — normalized spatial/time lattice

Discrete time or spatial labels can select among packets at a **fixed chosen scale**. They cannot supply a minimum when the primary physical-scale coordinate descends indefinitely.

## 5. Dependency consequence

In particular, the paper's later statements that a strict descendant is a terminal/rank-zero exit rely on a terminal selection that rules out indefinite strict descent. Until the scale component is repaired, those uses cannot be certified from the stated well-foundedness argument alone.

## 6. Comparison with established Type-I extraction practice

Albritton–Barker, arXiv:1811.00502, characterize local Type-I singular behavior through nontrivial mild bounded ancient solutions with a Type-I decay condition and use blow-up/zooming procedures. Their source-level framework is naturally sequence-based: the existence of a singularity produces rescaled limits along scales/times rather than requiring a smallest singular physical scale.

The transferable lesson is narrow: **sequence extraction plus compactness is legitimate; terminal minimality needs an additional theorem.** The Albritton–Barker result does not supply the missing Shahmurov strict-descendant terminality theorem and does not by itself close `NS-B1a1`.

## 7. Repair obligations before any RAKL transfer

The flux-hull / selected-output mechanism from arXiv:2606.07875v1 must not be imported into `NS-B1a1` as an established method until one of the following is proved with exact hypotheses:

1. **Truncated terminal selector + stable limit:** select terminal packets above a finite lower scale and prove that a limit as the cutoff vanishes inherits the no-strict-descendant property.
2. **Ordinal/rank extension:** augment scale descent with a genuinely well-founded ordinal or finite monotone rank that decreases on every strict descendant, including scale descendants.
3. **Charged scale descent:** prove each strict scale decrease spends a uniform positive amount of a globally finite currency, or another summable charge strong enough to prevent infinitely many descents.
4. **No-recrossing/persistence theorem:** prove that after a selected threshold crossing, sufficiently smaller descendants cannot re-cross the singularity-forcing level except through an already charged/output mechanism.
5. **Different compactness-rigidity closure:** abandon terminal minimality and prove directly that every infinite descending sequence yields an ancient limit satisfying a source-valid rigidity theorem.

Each repair is a new mathematical obligation. None may be inferred from the source's terminology `well-founded` alone.
