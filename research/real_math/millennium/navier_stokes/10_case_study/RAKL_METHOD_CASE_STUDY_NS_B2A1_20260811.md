## What worked

The two-packet calibration preserves a nonzero local limit while keeping a positive amount of tail mass in a packet escaping to infinity. It therefore isolates a stronger obstruction than a pure moving-core example: source nontriviality at fixed scale does not repair the abstract topology gap.

The result is exact and elementary at its registered scope. It shows that fixed-cylinder convergence, even stronger local convergence than the source needs, cannot by itself establish

`lim_{R->infinity} sup_k Tail_k(R)=0`.

This is retained as one semantic research-control result with multiple axis tags, not as multiple independent discoveries.

## Process incident and framework/tooling hypothesis

At the start of this cycle, a connector write was attempted to a branch before that branch existed. The write API defaulted to `main` when explicitly retried there, creating only an empty `{}` context placeholder. It was immediately removed in the next commit before any scientific content was written. The incident created no scientific authority and is preserved as repository history.

**Hypothesis:** research repositories using autonomous coding connectors should require a content-bound branch-existence/write-target guard before any scientific artifact write, with direct `main` writes blocked unless an explicit operator override is recorded. This is an external repository/tooling safety hypothesis, not evidence that the RAKL research method improved. One incident is insufficient for framework promotion.
